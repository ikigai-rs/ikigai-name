# AGENTS.md

`ikigai-name` is persistent-identifier resolution as an ikigai module (`urn:name:*`), with an
optional standalone server.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Run fmt, clippy (`-D warnings`) and the tests with every feature on, `server` included, before
  opening a pull request; CI runs the shared Rust workflow with `features: "*"`.
- Security reports go through
  [private vulnerability reporting](https://github.com/ikigai-rs/ikigai-name/security/advisories/new),
  never a public issue.
- Write American spelling (behavior, color, labeled).
